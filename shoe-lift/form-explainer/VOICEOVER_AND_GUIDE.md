# Shoe Lift Order Forms: Motion Graphics Explainer

A HyperFrames composition (`index.html`) that walks through the three American Heelers forms and highlights every field that needs to be filled in.

- **Format:** 1080×1920 (9:16), 30 fps, 63 seconds, no audio baked in
- **Render:** `renders/form-explainer.mp4`
- **Edit:** `npm run preview` opens HyperFrames Studio. Click any text to change it.
- **Re-render:** `npm run render`

## Highlight key

| Look | Meaning |
|---|---|
| Gold ring + red **REQUIRED** tag, glowing | Must be filled in |
| Ring turns **green** + check badge | Field completed |
| Dashed gray ring + **OPTIONAL** tag | Helpful, not required |
| Red ring + red X + **LEAVE BLANK** | Don't touch (office use) |

Sample data in the video (Jane Doe, 555 phone number, Akron address, 3/4 in, W 9 Brooks) is placeholder text only.
